# Sensor fixtures

Small, curated HID reports recorded in Milestone 0 with `Tools/sensor-log`, used to unit-test
`kf_sensor_decode_report()`. Keep each file under 100 KB; full logs stay in `/logs/` (git-ignored).
Record the Mac model and macOS version in each file's name, for example
`Mac14,2_macos-26.1_soft-taps.csv`.
